# QA 체크리스트 — 마이페이지/북마크/피드백/로그인 안내

최근 작업분(로그인 안내 모달, 피드백 모달 개선, 마이페이지 풀이내역/북마크 개편, 시험지 등록 안내 문구)에 대한 수동 테스트 체크리스트입니다.

공통 준비물: 로그인 계정 1개(테스트용), 문항이 여러 개 있는 과목/연도 조합, 북마크한 문항 2개 이상(서로 다른 과목 포함 권장).

---

## 1. 로그인 안내 모달

**전제**: 로그아웃 상태

- [ ] 헤더 드롭다운(유저메뉴 아이콘) 클릭 → 로그아웃 상태면 메뉴 자체가 안 보이는지 확인 (로그인 버튼만 노출)
- [ ] 문항 상세/암기모드/시험모드 화면에서 **북마크 아이콘** 클릭
  - [ ] "로그인 안내" 모달이 뜨는지 (바로 로그인 페이지로 안 튕기는지)
  - [ ] 모달에 로그인 시 가능한 기능 목록(문항 북마크 / 문제·해설 오류 제보 / 시험지 등록 / 마이페이지 풀이 내역 확인)이 보이는지
  - [ ] "취소" 클릭 → 모달만 닫히고 페이지 그대로인지
  - [ ] 다시 열어서 "로그인" 클릭 → `/auth/login`으로 이동하는지
  - [ ] 로그인 완료 후 **원래 보고 있던 페이지로 복귀**하는지
- [ ] 같은 방식으로 **피드백 제보(🚩) 아이콘**, **시험지 등록**(헤더 드롭다운) 클릭 시에도 동일하게 로그인 안내 모달이 뜨는지

---

## 2. 피드백 모달

**전제**: 로그인 상태

### 2-1. 문제 페이지에서 진입 (암기모드/시험모드/공유 문항 페이지)

- [ ] 🚩 아이콘 클릭 → 모달에 카테고리 **4개**(문제/해설 오류, 사이트 버그, 기능 제안, 기타) 모두 보이는지
- [ ] "문제/해설 오류" 선택 → **문항 번호**가 화면에 표시된 번호와 동일하게 자동으로 채워지는지 (읽기 전용, 직접 수정 불가한지)
- [ ] "문제/해설 오류" 선택 시 **관련 페이지 URL** 필드도 같이 보이는지
- [ ] "사이트 버그" 선택 → 문항 번호 필드는 사라지고 URL 필드만 남는지
- [ ] "기능 제안" / "기타" 선택 → 문항 번호·URL 둘 다 사라지고 **내용만** 남는지
- [ ] 내용 입력창에 **붙여넣기(Cmd/Ctrl+V)** 가 되는지 (문제 본문 자체는 여전히 복사가 안 되는지 같이 확인)
- [ ] 저장 후 "접수되었습니다" 안내가 뜨는지

### 2-2. 문제 맥락 없는 곳에서 진입 (헤더 드롭다운 "피드백")

- [ ] "문제/해설 오류" 카테고리 자체가 **안 보이는지** (사이트 버그/기능 제안/기타 3개만 노출)

---

## 3. 마이페이지 — 북마크 탭

**전제**: 로그인 상태, 북마크 2개 이상(다른 과목 포함)

- [ ] 북마크 탭 진입 → 과목별로 섹션이 나뉘어 전부 펼쳐져 보이는지 (페이지네이션 없음)
- [ ] 각 문항 카드에 표시되는 라벨이 내부 파일명(`253-데이터베이스-...` 같은 형태)이 아니라 `연도 · 시험종류` 형태로 보이는지
- [ ] 각 과목 섹션 헤더 옆 **"과목별 복습"** 버튼 클릭 → `/mypage/bookmarks/review?subject=...`로 이동하며 **그 과목 문항만** 순서대로 나오는지 (다른 과목 문항 안 섞이는지)
- [ ] 복습 화면에서 1/N → 2/N 형태로 번호가 올라가는지, 이전/다음 버튼 정상 동작하는지
- [ ] 문항 카드 클릭(제보/공유/북마크 아이콘 제외) → `/memorize/:questionId` 공유 문항 페이지로 이동하는지

---

## 4. 북마크 문항 상세 페이지 (`/memorize/:questionId`)

- [ ] 진입 시 정답이 바로 안 보이고, 선택지만 보이는지 (정답 미공개 상태)
- [ ] 답 하나 선택 → "정답 확인" 버튼이 활성화되는지 (선택 전엔 비활성화)
- [ ] "정답 확인" 클릭 → 내가 고른 답/정답이 색으로 구분(정답=초록, 오답=빨강)되는지
- [ ] 해설이 있는 문항 → 해설 영역이 나오는지 (광고 클릭 잠금 화면 포함해서 정상 동작하는지)
- [ ] 해설이 없는 문항 → "등록된 해설이 없습니다." 문구가 보이는지
- [ ] 브레드크럼 / 상단 정보 줄에 내부 파일명이 아니라 `과목 연도년` 형태로 보이는지
- [ ] 🚩 제보 아이콘 클릭 → 문항 번호가 화면에 보이는 번호와 동일하게 자동으로 채워지는지

---

## 5. 마이페이지 — 내가 풀었던 문제 탭

**전제**: 로그인 상태, 시험 제출 이력 1건 이상 (없으면 시험모드에서 하나 제출)

- [ ] 목록 상단에 **"같은 과목·연도 시험을 다시 풀면 이전 기록은 이번 결과로 대체돼요"** 안내 배너가 보이는지
- [ ] 각 카드에 **"결과 보기" / "다시 풀기"** 버튼이 나란히 있는지 (카드 전체 클릭은 더 이상 안 되는지)
- [ ] 버튼에 마우스 올렸을 때 파란색으로 hover 효과가 보이는지
- [ ] **"다시 풀기"** 클릭 → 해당 시험 시험모드로 바로 진입하는지
- [ ] **"결과 보기"** 클릭 → `/mypage/history/:attemptId`로 이동하며,
  - [ ] 상단에 과목명 · 연도 · 시험종류가 **빈 값 없이** 제대로 보이는지
  - [ ] 점수 카드(획득 점수/정답률), 정답·오답 통계 카드가 실제 값으로 채워지는지
  - [ ] 문항 네비게이터에서 정답=초록/오답=빨강으로 구분되는지, 번호 클릭 시 해당 문항으로 이동하는지
  - [ ] 문제 카드에 내가 고른 답 vs 실제 정답이 하이라이트되는지
  - [ ] "해설 보기"/"해설 숨기기" 토글 정상 동작하는지 (해설 없으면 "등록된 해설이 없습니다.")
  - [ ] 이전/다음 버튼으로 문항 넘기기 정상 동작하는지
  - [ ] 상단 "← 마이페이지로" 링크만 있고, 하단에 중복된 "마이페이지로 돌아가기" 버튼은 없는지
- [ ] **재응시 시나리오**: "다시 풀기"로 같은 과목·연도 시험을 다시 제출 → 마이페이지 목록에 새 카드가 추가되는 게 아니라 **기존 카드 1개가 최신 결과로 대체**되는지 확인

---

## 6. 시험지 등록 모달

**전제**: 로그인 상태, 헤더 드롭다운 → "시험지 등록"

- [ ] 과목명 드롭다운을 열었을 때 목록 높이가 제한되고 내부 스크롤이 되는지 (전체 화면을 덮지 않는지)
- [ ] 과목명 드롭다운 안 **검색창**에 일부 글자 입력 → 해당하는 과목만 필터링되는지
- [ ] 이미 등록된(중복) 과목/연도/시험종류 조합으로 제출 시도 → "입력값을 다시 확인해 주세요." 같은 모호한 문구가 아니라, **중복 등록임을 알 수 있는 안내 문구**가 뜨는지
